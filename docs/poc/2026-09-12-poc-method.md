# 느링고 역할극 PoC · 측정 방법

## 1. 목적

이 PoC는 느링고 역할극 흐름에서 후보 모델이 실제로 응답을 준비하는 데 걸리는 시간, 토큰 사용량, 재생성 횟수, 안전 처리 결과를 기록하는 실험이다.

목표는 특정 모델이 무조건 더 좋다고 단정하는 것이 아니다. 현재 수준의 기준값을 남기고, 이후 프롬프트·호출 구조·모델을 바꿨을 때 얼마나 달라졌는지 확인하는 데 사용한다.

## 2. 비교 범위

| 항목 | 내용 |
| --- | --- |
| 공통 시나리오 | `SCN-GEN-16DE81D6` — 발표하다가 말을 못 해서 앉은 친구 |
| 비교 단위 | 공통 아동 발화 14턴 |
| 구성 | play 2턴 · safety 6턴 · ladder 6턴 |
| 시나리오 DB 턴 상한 | 6턴 |
| 비교 모델 | Claude Haiku 4.5 · GPT-5.4 mini · Gemini 3.1 Flash Lite |
| 바꾸는 값 | 모델과 해당 모델의 Elice 엔드포인트 |
| 고정하는 값 | 시나리오, 아동 발화 순서, 프롬프트, 출력 한도, 후보 최대 횟수, Moderation 모델 |

테스트에 쓰는 실제 아동 발화와 각 턴의 확인 목적은 [test-scenario.md](test-scenario.md)에 정리했다. 아이의 발화는 고정하지만, 캐릭터와 마스코트의 답변은 모델별로 달라지는 관찰 대상이므로 미리 정답으로 정하지 않는다.

## 3. 사용 도구와 모델

| 구분 | 사용 내용 |
| --- | --- |
| 역할극 서버 | Python · FastAPI |
| 모델 호출 | Elice MLAPI의 OpenAI 호환 API |
| 안전 2차 확인 | OpenAI `omni-moderation-latest` |
| 측정 실행 | `python -m scripts.simulate` |
| 결과 보고서 | `python -m scripts.report_run` |
| 데이터 저장 | SQLite DB, `timings.csv`, `turns.jsonl`, `sessions.json`, `summary.md` |

모델은 Elice 엔드포인트와 모델 ID를 함께 바꿔 설정한다. 안전성 지표를 비교할 때는 `OPENAI_MODERATION_MODEL`을 바꾸지 않는다.

## 4. 실행 절차

1. `server/.env`에서 측정할 모델의 Elice 엔드포인트와 모델 ID를 설정한다.
2. Moderation API 키를 설정하고 서버를 다시 시작한다.
3. 고정 시나리오와 세 스위트를 실행한다.
4. 실행이 끝나면 같은 `run-id`로 Markdown 보고서를 생성한다.
5. 모델별 결과에서 공통 14턴만 골라 비교표에 기록한다.

```powershell
# server/에서 실행
uvicorn app.main:app --port 8000

python -m scripts.simulate `
  --scenarios SCN-GEN-16DE81D6 `
  --suites play,safety,ladder `
  --run-id <모델-회차-id> `
  --note "모델 비교"

python -m scripts.report_run --run-id <모델-회차-id>
```

`play`는 목표 달성 시점에 따라 P3 이후까지 이어질 수 있다. 이 경우에도 세 모델에 공통으로 들어 있는 P1·P2만 비교 집계에 사용하고, 추가 턴은 실행 로그에는 남긴다.

## 5. 기록하는 지표

| 관점 | 기록값 | 보는 이유 |
| --- | --- | --- |
| 응답 속도 | 턴 전체 p50·p95, 단계별 소요 시간 | 아이가 기다리는 시간과 병목 위치 확인 |
| 토큰 | 단계별 입력·출력 토큰, 잘림 횟수 | 비용과 긴 프롬프트·출력의 영향 확인 |
| 생성 품질 | 후보 통과·재생성 횟수, 기본응답 여부, 실패 코드 | 추가 호출을 만드는 원인 확인 |
| 학습 흐름 | 목표 달성·포기, 도움 세기 변화 | 스스로 이해한 경우와 도움을 받은 경우 구분 |
| 안전 | 욕설·개인정보·위험 발화 처리, 마스킹 여부 | 아동 대상 서비스의 기본 안전 동작 확인 |

## 6. 결과 해석 시 유의점

- 현재 결과는 모델당 1회 실행한 탐색 결과다. 최종 p50/p95 비교는 같은 조건으로 3회 이상 반복한 뒤 사용한다.
- 이 실험은 고정 대본을 다시 재생한 파이프라인 측정이다. 실제 아동 대화의 학습 효과나 만족도를 직접 증명하지는 않는다.
- 모델별 결과에는 모델 ID, 실행 조건, 프롬프트 해시, 코드 버전, 반복 횟수와 함께 기록을 남긴다.
