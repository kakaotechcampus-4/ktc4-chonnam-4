# 캐릭터 역할극 공통 판정 정책

아동은 등장인물에게 직접 말한다. 안내자의 문제에 정답을 쓰는 문답으로 바꾸지 않는다. 아래 정책은 분석과 독립 검수가 함께 사용한다.

- 작은 목표에는 순서·선행 통과 조건이 없다. 현재 목표는 이번 학습 상태를 판단할 초점이고 다음 전략의 목표는 다음 대화 초점이다. 현재 목표가 미달성이어도 다른 목표를 다룰 수 있다. ADVANCE_GOAL이라는 이름이나 목표 ID 변경을 달성 주장으로 해석하지 않는다.
- GOAL_ACHIEVED에는 현재 목표의 실제 긍정 증거가 필요하다. 반면 PARTIAL_UNDERSTANDING은 목표 달성 선언이 아니다. 현재 목표 증거가 없더라도 다른 목표의 증거가 있거나 상황에 맞게 등장인물을 걱정·돕는 말이면 부분 이해로 판단할 수 있다. 관찰은 NOT_EXPRESSED인 채로 남을 수 있다.
- “도와줄까”, “부축해 줄까”, “괜찮아?”처럼 상황에 이어지는 도움 제안·걱정은 캐릭터와 상호작용하려는 ANSWER_ATTEMPT로 볼 수 있다. 도움을 제공하는 것과 아동이 정답을 얻기 위해 도움을 요청하는 HELP_REQUEST를 구분한다. 질문형이라는 이유만으로 QUESTION_BACK·HELP_NEEDED로 바꾸지 않는다. 맥락과 승인된 학습 기준을 함께 판단한다.
- 도움 제안만으로 구체 목표의 정답을 관찰했다고 만들지 않는다. 상태·발화 행위·목표별 관찰·활동 전체의 달성은 각각 검수한다.
- S3는 해당 목표의 직접 답 제공을 허용하지만 아동의 독립 달성이 아니다. 이전 정답 제공·단서·힌트 이력을 지우지 않는다. 이미 답을 제공한 목표를 다시 유도하거나 같은 목표의 지원을 낮추지 않는다.
- 후보에서 도움을 필요로 하는 인물과 도움을 주는 인물을 뒤집지 않는다. 등장인물이 도움을 요청해야 하는 상황에서 아동에게 오히려 도움을 요청하라고 시키면 역할·대화 정합성을 검수한다. 마스코트 안내와 등장인물 대사를 섞지 않는다.
- GOAL_SKIPPED는 미관찰 목표를 달성했다고 주장하거나 근거 없이 마무리한 실제 위반에 사용한다. 초점만 바꾼 것을 거절하지 않는다. 실제 오류는 거절하며 정책에 맞추려고 모든 검수를 승인하지 않는다.
