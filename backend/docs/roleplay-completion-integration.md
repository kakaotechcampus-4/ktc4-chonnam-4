# S3-JIN-02 완료 트랜잭션 참여 계약

기준: develop `9f6ffa5`, 2026-10-28. 이 브랜치는 S3 본체만 포함한다.
PR #76 기반의 실제 완료 서비스·관찰/지원 확장은 별도 작업본에 보존했다.

## 현재 제공하는 경계

`JpaRoleplayCheckpointStore.commitInCurrentTransaction`은 호출자의 완료 트랜잭션에 참여한다.
외부 AI 호출은 먼저 끝내고 활동→아동→세션 잠금, 마지막 저장 버전 검사를 유지한다.
상위 트랜잭션이 없으면 쓰지 않고 실패한다. 기존 독립 `commit`의 REQUIRES_NEW 동작은 유지한다.
반환한 Committed는 상위 트랜잭션이 커밋될 때까지 미확정이다. 모든 업무 저장과 최종 기한 검사 후 응답해야 한다.
replayed=true이면 기존 결과이며 완료·보상·기록·삭제 효과를 다시 적용하지 않는다.

`RoleplayCanonicalRetentionService.completeNormallyAndDelete`는 같은 트랜잭션에서 정상 종료·표준 발화 삭제에 참여한다.
삭제 뒤에도 확정 응답·후보·체크포인트가 남아 같은 요청을 복원한다. 삭제 건수0을 완료 실패로 해석하지 않는다.
정상 완료 기준은 사용자가 확인한 각 역할극의 활동 목표 달성이다. 마무리 문장이나 작은 목표 하나의 도달만으로 완료하지 않는다.

## 공급 서비스와 연결할 부분

현재 develop에는 PR #76의 실제 활동 완료·스탬프·학습 기록·status 전용 조회가 포함되지 않았다.
이 PR은 그 코드를 함께 가져오거나 별도 보상 테이블을 제품에 추가하지 않는다.
공급자가 트랜잭션 안에서 마지막 턴 저장, 실제 완료·기록·지급, 세션 종료·발화 삭제를 호출해야 한다.
일반 역할극의 완료·상태 조회 연동은 해당 공급 코드 통합 후 검증해야 한다.
기술/안전 종료, 고정 최대 턴, 요청 키 TTL/lease는 이 변경에서 새로 정하지 않았다.

## 검증 범위

RoleplayAtomicCompletionIntegrationTest는 실제 PostgreSQL과 체크포인트/삭제 구현을 사용하고,
완료·지급·학습 기록은 테스트 전용 테이블/fixture로 대체한다. 실제 제품 완료 서비스의 종단 실행이 아니다.
동시/재전송의 기록1회, 다른 입력 충돌, 기록 실패·취소의 전체 롤백/재시도, 상위 트랜잭션 필수를 선별 확인했다.
배정/음성/종료 설정을 합친 이번 최종 선별 검사는 16개 통과, 실패·오류·건너뜀0이다.
전체 회귀·실제 AI·브라우저·운영 배포는 실행하지 않았다.
