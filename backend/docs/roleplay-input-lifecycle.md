# 역할극 입력 수명주기

- 선행 브랜치: `feat/roleplay-input-recovery`, `feat/roleplay-audio-validation`.
- 서버가 소유한 업로드 디렉터리에 multipart 본문과 검사 파일을 저장한다. 프로세스 소유권 잠금으로 현재 사용 중인 파일을 구별하고, 다음 시작에서 소유권이 끝난 디렉터리의 알려진 업로드 파일을 정리한다.
- 음성·텍스트 입력에는 세션별 사용 권한을 부여한다. 음성 HTTP 요청은 인증·권한 확인 뒤 multipart 본문을 읽기 전부터 권한을 보유한다. 만료 삭제는 유효한 입력이 끝난 뒤 시작하고 삭제 트랜잭션 종료 시 권한을 놓는다.
- 정상 완료와 미완료 24시간 만료 시 표준 발화·입력 품질·음성 실패 기록을 함께 삭제한다. 유효 기한이 지난 입력은 삭제를 무기한 막지 않는다.

검증: `./backend/gradlew -p backend --offline --no-daemon spotlessCheck build` 통과. 103개 검사 클래스, 1,613개 검사, 실패·오류·건너뜀 0개. 실제 브라우저·프록시 업로드 시작 시점과 다중 서버에서 공유하는 잠금은 확인하지 않았다.
