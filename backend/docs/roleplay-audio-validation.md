# 역할극 음성 파일 검증

- 입력 복구 브랜치 `feat/roleplay-input-recovery`를 선행 변경으로 사용한다.
- 업로드한 파일의 형식과 디코딩된 길이를 검사한다. 비어 있거나 손상되거나 지원하지 않는 파일, 30초 초과 파일, 검사 도구 장애는 재입력을 안내하고 음성 실패에 포함한다.
- 파일 크기를 넘었지만 전체 바이트를 읽은 경우 지문으로 중복 요청을 판별한다. 전체 바이트를 읽지 못한 경우 실패를 한 번 저장하고 같은 요청 번호의 재사용을 충돌로 처리한다.
- 업로드 요청이 서버에 도달한 때부터 60초 처리 기한을 시작한다. 브라우저·프록시 구간의 시작 시점은 프론트엔드 연동에서 확인해야 한다.
- 세 번째 음성 실패부터 텍스트 입력을 권하되 음성 입력은 유지한다.

검증: `./backend/gradlew -p backend --offline --no-daemon spotlessCheck build` 통과. 101개 검사 클래스, 1,603개 검사, 실패·오류·건너뜀 0개. 실제 FFmpeg 바이너리와 브라우저 업로드 종단 동작은 이 브랜치에서 확인하지 않았다.
